# Synthetic store panel (fake data)

Generated by `data_gen/generate_fake_data.py` (seed 7, 200 stores, 156 weeks, 8 categories).
All numbers are invented. Regenerate or scale with:

```
python data_gen/generate_fake_data.py --out data --n-stores 200 --n-weeks 156 --seed 7
```

## Model inputs (allowed in training)

| File | Grain | Columns |
|---|---|---|
| `stores.csv` | store | store_id, region (0–5), size_sqm, urban, income_index, competitor_dist_km, lidl_plus_share, experiment_cohort |
| `calendar.csv` | region × week | week, iso_year, week_of_year, national_holiday (christmas / easter / new_year / empty), regional_holiday, temp_c, rain_mm, temp_forecast_c, rain_forecast_mm, national_bread_flyer |
| `sales.csv.gz` | store × week × category | units_sold, base_price, discount (fraction), net_price, randomized (1 = experiment week for bread), experiment_slot (1 = bread discount drawn at random this week), stock_units, stockout_hours (of 78 opening hours), waste_units, unit_cost, margin_eur |

Categories: bread, rolls, dairy, spreads, produce, drinks, snacks, household.
The action is the bread discount (0, 0.1, 0.2, 0.3). Other categories have occasional
planned promos that count as known-future information, not as actions.

`randomized = 1` marks experiment-cohort stores inside experiment windows (weeks 30–49,
80–99, 110–125, 132–151). Inside a window every third week gets a random bread discount
level (0, 10, 20 or 30%) and is marked `experiment_slot = 1`; the two weeks after it are
0% washout weeks. Compare slot weeks with each other for clean effect estimates. Outside the
experiment, bread discounts are observational and confounded.

`units_sold` is censored: sales = min(demand, stock). `stockout_hours > 0` signals censoring.

## Ground truth (evaluation only, never a model input)

| File | Content |
|---|---|
| `ground_truth/store_traits.csv` | bread_beta (true price sensitivity), halo, competitor_open_week, road closure |
| `ground_truth/demand.csv.gz` | true uncensored demand and the hidden traffic shock per store-week |
| `ground_truth/counterfactuals.csv.gz` | for every store and start week ≥ 104 and every discount level d: the true outcome of the action sequence [d, 0, 0, 0] on bread — bread_units_w0..w3, bread_units_4w, bread_margin_4w, total_margin_4w |
| `manifest.json` | parameters, suggested split, and sanity checks (true effect vs randomized diff-in-means vs naive observational estimate) |

## Built-in mechanisms the model should discover

- Store-specific bread price sensitivity, partly predictable from income, competitor
  distance and Lidl Plus share, partly hidden.
- Halo (more visitors), cannibalisation (rolls), complement (spreads).
- Pull-forward: 30% of the extra bread volume is lost the week after, 10% two weeks after.
- Stock-outs under deep discounts in sensitive stores (about 11% of bread weeks censored).
- Confounded observational promos: more likely in holiday weeks, weak-traffic weeks
  and price-sensitive stores. The naive estimate overstates the effect by 10–25%.
- Unobserved shocks: AR(1) traffic noise, competitor openings (−12% traffic, permanent),
  road closures (−25%, 3–6 weeks).

In the test period, the best discount by true 4-week total margin is 0% for about 67%
of store-weeks, 10% for 22%, 20% for 10% and 30% for 1%. A good planner beats "never
discount" by picking the stores and weeks where a discount pays off.
